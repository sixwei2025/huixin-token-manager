# 本机连接说明

当前仅支持 Apple 芯片 Mac、macOS 14+；Windows / Intel Mac 暂不支持。应用内已包含读取引擎，不需要另装 CodexBar。

Codex：先安装 Codex CLI 并完成本人账号登录。Antigravity：先在本机登录并启动应用。Grok Bot：需要 Cursor 体系中存在独立 Grok Bot 额度字段的会话；没有该字段时不会使用 Cursor 总额度。WorkBuddy：先在本机浏览器登录自己的 WorkBuddy 网站，再刷新面板。不同浏览器的会话读取支持以固定版本 CodexBar 引擎为准。

在面板右下角点击“连接与来源”，对 Grok Bot / WorkBuddy 点击“连接浏览器”可主动请求读取本机网页登录。自动刷新不会主动弹授权框。

首次读取浏览器 Cookie 或钥匙串可能出现系统提示，请本人查看来源并决定是否允许。不要将密码、Cookie、Token 发送给作者或公开 issue。应用不自动绕过系统授权。

如果以前使用过 CodexBar，内置引擎可能复用本机的上游配置或授权缓存，这些配置保留在本机；卸载旧的 CodexBar 应用不会把你的账号配置打进新安装包。全新用户不需要作者的配置文件，本应用会显式读取四个指定来源。各工具的登录前提仍然必要。

读取失败时检查：对应工具是否已登录、浏览器是否已登录、登录是否过期、是否存在所需独立字段、是否拒绝了必要的本机读取提示。若仍失败，报告系统版本、应用版本、工具名和通用错误即可，不上传完整原始响应。

当前引擎固定为 CodexBar v0.84.0，其完整开源代码见 https://github.com/steipete/CodexBar/tree/v0.84.0 。不会后台自动下载或执行未知引擎。升级由后续公开版本完成。

临时签名版不会把浏览器会话缓存写入不受信任的共享钥匙串缓存项。v1.0.2 使用常驻读取进程，让连接与多次后台刷新复用内存中的已验证会话；完全退出或升级后可能需要重新连接。

首次系统授权需要本人操作。如果授权窗口等待较久，应用可能先提示读取超时；完成系统授权后再点击一次“连接浏览器”即可重试，自动刷新不会替用户绕过授权。
