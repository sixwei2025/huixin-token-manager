# 连接说明 · v1.1.0

应用名称：汇芯 token 管家。菜单栏、页面和应用使用同一三柱标识。支持 Apple Silicon / macOS 14+。

## Codex 与 Antigravity

复用 CodexBarCore v0.85.0 的本机登录来源选择与读取策略。请先安装并登录原工具。各自常驻进程独立更新，不读取成本历史，不启动全局消费报表。

## WorkBuddy

1. 在 Chrome 打开 https://www.workbuddy.cn/profile/plans-usage 并登录自己的账号。
2. 在管家的 WorkBuddy 卡片点击“连接 WorkBuddy”。
3. 首次访问 Chrome 会话可能出现 macOS 钥匙串授权，由本人决定并输入系统密码；不要把密码、Cookie、Token 复制给聊天。
4. 授权成功后同一个读取进程复用已验证会话，后台同步不重复请求本人授权。

WorkBuddy 网页会话与浏览器 User-Agent 绑定，上游会匹配已安装 Chrome 及其前一个主版本。桌面客户端登录不等于网页登录；本应用不读取或解密 WorkBuddy 桌面客户端的加密 Token。

账号切换、浏览器更新或会话过期时，主动重新连接。完全退出或更新应用后，内存会话结束，可能需要再次连接。

正常更新为30秒、低电量60秒。临时错误自动退避，最长5分钟；登录或授权失败停止自动重试，在卡片保留连接入口。其他服务不会被拖住。手动更新不叠加同服务请求。

## 数据与预测

只在本机缓存额度、周期、更新时间和最多2小时匿名趋势，不存邮箱、Cookie 或原始响应。上次数据有明确状态提示，不冒充实时数据。

预测以 CodexBarCore 的真实周期均速为基础，近期记录足够后参考最近1小时的实际消耗。近期预测至少3个观测、跨度10分钟且有实际消耗；恢复、充值和套餐容量变化后重新计算。预测会随强度变化，非确定承诺。
